## What is the W3C WCAG 2.0 Level A standard?
WCAG 2.0 is a stable, referenceable technical standard. It has 12 guidelines that are organized under 4 principles: perceivable, operable, understandable, and robust. For each guideline, there are testable success criteria, which are at three levels: A, AA, and AAA. See: http://www.w3.org/WAI/intro/wcag

## What is PDF/UA?
UA stands for “Universal Accessibility”. PDF/UA is a subset of PDF files. Some PDF files qualify as “PDF/UA”.

## What is ISO standard 14289-1:2012 for PDF/UA?
PDF/UA(PDF/Universal Accessibility) is the informal name for ISO 14289, the International Standard for accessible PDF technology. A technical specification intended for developers implementing PDF writing and processing software, PDF/UA provides definitive terms and requirements for accessibility in PDF documents and applications.

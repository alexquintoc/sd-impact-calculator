## Visual impairment levels

Design for different levels of visual cognition. This may include the use of braile technology for blind audiences.

| Visual Acuity (Better Eye with glasses) | WHO Classification | Description |
| ------------- |:-------------:| :-------------: |
| 20/30 to 20/60      | Mild visual impairment    | Near-normal vision |
| 20/70 to 20/160      | Moderate visual impairment     | Moderate low vision |
| 20/200 to 20/400      | Severe visual impairment    | Severe low vision |
| 20/500 to 20/1,000      | Profound visual impairment    | Profound low vision |
| Less than 20/1,000      | Near-total visual impairment    | Near-total blindness |
| No light perception     | Total visual impairment   | Total blindness |

See [WHO's factsheet on blindness and vision impairment] (https://www.who.int/news-room/fact-sheets/detail/blindness-and-visual-impairment)

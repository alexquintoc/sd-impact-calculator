# Project Overview

This project explored ways to reduce print waste and transportation emissions through regional production and reduced ink coverage.

## Sustainability Strategies

- reduced print quantities
- local print production
- lighter paper stock
- QR-linked supplemental information

## Outcomes

The redesign reduced material use by approximately 40%.

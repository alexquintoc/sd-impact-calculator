# Project Overview

This exhibit kit uses durable panels, reusable hardware, and locally adaptable content modules to support repeated installations.

## Sustainability Strategies

- modular structure
- durable display hardware
- local cultural adaptation
- reusable transport packaging

## Outcomes

The exhibit can be reconfigured for multiple venues without rebuilding the core display system.
